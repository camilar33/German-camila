# Deutschheft

Caderno de alemão rumo ao B1 (maio de 2027): flashcards com repetição espaçada, exercícios de 5 minutos,
registro de tempo, plano por fases, Einbürgerungstest e carteira de motorista.

**Abrir:** https://camilar33.github.io/German-camila/

O progresso fica salvo no navegador do aparelho (localStorage). Funciona offline depois da primeira visita
e pode ser instalado na tela inicial do celular.
